# APKs — política do caso IR-001

Os APKs reais **não são publicados neste repositório** por defeito.

A documentação utiliza:

- nomes sanitizados de artefactos;
- SHA-256;
- certificados;
- resultados de análise estática;
- referências à evidência local preservada.

Consultar [`../evidence/EVIDENCE-MANIFEST.md`](../evidence/EVIDENCE-MANIFEST.md).
